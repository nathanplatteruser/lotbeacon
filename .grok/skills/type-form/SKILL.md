# type-form

Recall: run type form on [draft].

Use LotBeacon type form before Send to append typed judgments for:
- Noul violations (payments, approvals, trade values, OTD/doc fees, DNC override, sold/pending/stale availability, Sunday offers, invented slots, invented specs, credit/income asks, autonomous self-ID)
- Choice gate_action (`send_ready`, `edit_first`, `escalate_manager`, `suppress_dnc`)
- Scores (`groundedness`, `show_risk`)

Type form appends claims. It does not replace the regex firewall, VOICE_LAW, or Human Send.
